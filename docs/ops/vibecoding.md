# Vibecoding — contexto antes de codar

1. Lib nova? Puxe a doc oficial via Context7 antes de pedir código ao agente.
2. Inspirar em repo? Gere 1 blob com gitingest e entregue ao OpenCode em vez de 50 arquivos.
3. Lib obscura? Consulte o deepwiki e resuma para o agente.
4. Trocar de modelo? Confira janela/custo em models.dev + artificialanalysis (TR longo precisa de contexto grande; free tier estoura 429).
5. Auditoria E2E + falhas recentes? `./scripts/contexto-auditoria.sh` e cole com `.cursor/contexts/auditoria-e2e-falhas.md` (não peça feature nesse chat).
